# DataModel

* [Plugin source model](plugin-source-model.md) - The host-neutral shape of a plugin's source that pluginfinity reads, decodes and builds from — skills, agents, hooks, MCP servers and the config fields that declare them — as designed for the first release.
* [Target description](target-description.md) - The shape of core's Target schema — manifest, plugin-root spellings, component field maps, hook event tables, MCP and reference rendering — and the per-host values targets holds, as designed for the first release.
